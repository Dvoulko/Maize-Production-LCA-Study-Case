# Agribalyse-project
Σε αυτό το προτζεκτ δίνονται 3 πιθανά σενάρια περιβαλλοντικών επιπτώσεων, για την καλλιέργεια καλαμποκιού
1ο σενάριο: Συμβατική Καλλιέργεια καλαμποκιού
2ο σενάριο: Μείωση λίπανσης και μελέτη περιβαλλοντικών επιπτώσεων
3ο σενάριο: Έλεγχος ροής νερού κατά το πότισμα και μελέτη της μείωσης των περιβαλλοντικών επιπτώσεων
